# Project history and credits

iffy.ai began as a team project for **ProdX at NAVERA '26**. Muneer Alam was the project's creator and team lead, with Amrit Kang and Akshaj Garlapati; Anshuman Singh mentored the team. The original team copyright remains in [LICENSE](../LICENSE).

The previous README recorded a Top 7 placement among 350+ teams. That is retained here as a historical team claim from the [earlier repository README](https://github.com/Muneer320/iffy-ai/blob/c1082c5a8976eefe258b6d46fcad56a0a81770ef/README.md#provenance), not a newly verified metric or a current product badge.

The canonical repository was transferred from `muneer406/iffy-ai` to `Muneer320/iffy-ai` with its history and pull requests preserved. The separate `amritkang165/iffy-ai` copy was not overwritten. Surviving original commits are largely attributed to Amrit's Git account; that metadata does not establish the complete division of team work. No original authors were reassigned without individual evidence, and no deleted-original repository recovery is claimed.

The current frontend is a new consequence-notebook implementation. It replaces the original frontend source while retaining that source in Git history. `frontend_v2/` remains the alternate sprint experiment, outside the supported runtime and CI. The removed unresolved `frontend_v3` gitlink had no recoverable source in the earlier repository; this pass does not claim to restore it.

The existing backend's Groq generation, Zod validation/repair, mutation merge, sector and debate services were retained and repaired. New work adds the authored offline examples, persistent local notebook store, private live-mode gate, shared generation budget, graph integrity checks, Docker demo and regression coverage.

This repository now documents a working local prototype and an optional private provider integration. It does not claim a public deployment, an active community, marketplace transactions or calibrated policy forecasts.
